Personal Operations Gmail POC

Purpose and scope

Personal Operations Gmail POC is a private personal-use application operated for the Google accounts whose owner explicitly authorizes it. It is not offered as a public service.

Google user data accessed

The application requests only the Gmail metadata permission (https://www.googleapis.com/auth/gmail.metadata). This permission may provide access to Gmail message metadata such as message identifiers, labels, and headers needed to detect and reconcile mailbox activity. The application does not request access to Gmail message bodies.

How Google user data is used

Google user data is used only to provide the application's personal mailbox-monitoring, synchronization, reconciliation, and related reliability testing functions.

Storage and security

During this proof of concept, application state and reusable OAuth credentials are stored in an operator-controlled local environment. Reusable OAuth credentials are protected using Windows protected storage rather than being intentionally stored as plaintext.

Sharing and sale

Google user data accessed by this proof of concept is not sold, used for advertising, or shared with advertisers or unrelated third parties.

Retention and deletion

Data is retained only as needed for the application's personal operational and testing purposes. The operator can stop use of the application, revoke its Google Account authorization, and remove locally stored application data and credentials.

Google API Services User Data Policy

The application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Changes and contact

This policy will be updated if the application's handling of Google user data materially changes. Questions may be directed to the support contact identified on the application's Google OAuth consent screen.
