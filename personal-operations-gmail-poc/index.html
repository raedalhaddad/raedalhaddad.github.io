Personal Operations Gmail POC

A private proof of concept for reliable, metadata-only Gmail mailbox monitoring.

What this application does

Personal Operations Gmail POC is a private application used by the operator to test Gmail-native mailbox monitoring and synchronization for the operator's own Google accounts.

The application requests the Gmail metadata permission so it can identify mailbox changes and reconcile message metadata such as message identifiers, labels, and headers. It does not request permission to read Gmail message bodies, send mail, modify messages, or delete messages.

Google user data is requested only for the application's personal mailbox-monitoring and synchronization functionality.
